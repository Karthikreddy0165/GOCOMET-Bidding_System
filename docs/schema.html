Table Definitions

Complete column specifications, PostgreSQL data types, and integrity rules.

users Central authentication and Role-Based Access Control (RBAC)
Column Type Rules / Meaning
id Integer PK Auto-incrementing primary key
email String(255) UQ NOT NULL User login identifier
hashed_password String(255) NOT NULL Bcrypt salted password hash
role String(50) NOT NULL BUYER, SUPPLIER, or ADMIN (governs RBAC access)
full_name String(255) User display name
company_name String(255) Organization name (shipper or supplier)
is_active Boolean Account status flag (default: true)
created_at DateTime(UTC) Account registration timestamp
auctions Core auction lifecycle and dynamic close deadline management
Column Type Rules / Meaning
id Integer PK Auto-incrementing primary key
rfq_id Integer FK UQ References rfqs.id (1:1 RFQ to auction mapping)
name String(255) NOT NULL Unique among active auctions
status String(50) DRAFT, SCHEDULED, ACTIVE, EXTENDED, CLOSED, FORCE_CLOSED
start_at DateTime(UTC) NOT NULL Scheduled start time when auction opens for bidding
initial_close_at DateTime(UTC) NOT NULL Original planned close time prior to extensions
current_close_at DateTime(UTC) NOT NULL Dynamically updated close time (extended by qualifying bids)
forced_close_at DateTime(UTC) NOT NULL Hard close ceiling; extensions cannot push deadline past this
total_extensions Integer Count of dynamic extensions triggered (starts at 0)
current_l1_bid_id Integer FK References bids.id (current lowest qualified bid)
bids Supplier freight quotes, fee breakdowns, transit days, and rank positions
Column Type Rules / Meaning
id Integer PK Auto-incrementing primary key
auction_id Integer FK References auctions.id
supplier_id Integer FK References users.id (bidding supplier)
base_fare Numeric(12,2) NOT NULL Pure ocean / road freight charge
bunker_surcharge Numeric(12,2) Fuel surcharge (BAF)
terminal_handling Numeric(12,2) Terminal handling charges (THC)
doc_fee Numeric(12,2) Documentation / customs filing fee
total_amount Numeric(12,2) NOT NULL Landed sum: base_fare + bunker + thc + doc_fee
transit_time_hours Numeric(8,2) NOT NULL Transit duration. Primary tie-breaker for identical bids.
valid_until DateTime(UTC) Validity of quote expiration timestamp
rank Integer Computed position at submission time (1 for L1, 2 for L2, etc.)
idempotency_key String(100) UQ UUID preventing duplicate bid processing on network retry
submitted_at DateTime(UTC) Timestamp of quote ingestion. Second tie-breaker for ranking.
auction_configurations Buyer-configured trigger window, extension increments, and conditions
Column Type Rules / Meaning
id Integer PK Auto-incrementing primary key
auction_id Integer FK UQ References auctions.id (1:1 configuration mapping)
trigger_window_minutes Integer Minutes before close where qualifying bids trigger extension (default: 10)
extension_increment_minutes Integer Minutes added to deadline when qualifying quote is placed (default: 5)
bid_change_trigger Boolean Extend if any new bid arrives within trigger window
rank_change_trigger Boolean Extend if quote causes rank positions to shift
l1_change_trigger Boolean Extend if lowest bidder (L1) changes inside trigger window

Data Integrity Invariants

Business invariants governing data consistency, concurrency, and deadlines.

INVARIANT 01
Unique Active Auction Names
Only one active or scheduled auction may exist with a given name at any time. When an auction is closed or completed, a new auction may reuse the name. This prevents buyer confusion and duplicate bidding rooms.
INVARIANT 02
Single-Supplier Duplicate Quote Guard
A supplier cannot quote the exact same landed cost twice in the same auction. They must submit a lower rate or an improved commercial offer. Price ties between different suppliers are allowed and resolved by transit time.
INVARIANT 03
Forced Close Ceiling Guarantee
Auctions can never run indefinitely. The system guarantees that forced_close_at > initial_close_at, and every dynamic extension is strictly capped at: min(current_close + increment, forced_close).
INVARIANT 04
Role-Based Data Isolation (RBAC)
The database schema isolates permissions: only users with role = BUYER can create RFQs and configure auctions. Only users with role = SUPPLIER can submit bids. The forced close ceiling is never exposed to supplier queries.
